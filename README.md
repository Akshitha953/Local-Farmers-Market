# 🌾 Local Farmers Market (FarmFresh)

A front-end web marketplace concept that connects local farmers directly with customers, so fresh produce reaches buyers without middlemen.

> This is a student project built to practise web development with HTML, CSS and JavaScript. Product names, prices and images are sample data.

## Features

- Landing page with a hero banner and call-to-action
- "Why Choose Us" section highlighting fresh produce, delivery and fair prices
- Product listing for six vegetables, each with an image, price and **Add to Cart** button
- Search box for finding products
- About and Contact sections
- Page navigation with anchor links

## Built With

- HTML5
- CSS3
- JavaScript



## Run Locally

1. Clone the repository: `git clone https://github.com/Akshitha953/Local-Farmers-Market.git`
2. Open `index.html` in your browser. No installation needed.
